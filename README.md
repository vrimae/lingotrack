# LingoTrack 🎓
> Platform Pelacak Kecakapan Bahasa Inggris untuk Mahasiswa Indonesia

[![Cloudflare Pages](https://img.shields.io/badge/Deploy-Cloudflare%20Pages-F38020?logo=cloudflare)](https://pages.cloudflare.com)

Aplikasi web pelacak kecakapan bahasa Inggris terstruktur untuk mahasiswa Indonesia yang mempersiapkan ujian sertifikasi internasional (TOEFL / IELTS) serta kemampuan akademik perkuliahan.

## 🌟 Fitur Unggulan
- **Onboarding Personalisasi**: Form pendaftaran khusus mahasiswa (email kampus `.ac.id`, jurusan, target skor TOEFL/IELTS, waktu belajar harian).
- **Placement Test Adaptif**: Soal CEFR (A1–C1) yang menyesuaikan tingkat kesulitan secara otomatis dengan umpan balik langsung.
- **Dasbor**: Level CEFR, akumulasi XP, penghitung streak harian, dan grafik tren skor 30 hari (HTML5 Canvas 2D murni).
- **Kuis Level Grammar & Vocab**: Soal pilihan ganda akademik dengan penjelasan dan perolehan XP.
- **Audio Dictation B2**: Dikte listening dengan batas 3x putar dan analisis per kata (*benar, salah ejaan, kata hilang, kapitalisasi, kata tambahan*).
- **Vocabulary Builder**: Kosakata A1–B2 lengkap dengan tombol pelafalan suara (Text-to-Speech) dan mode latihan kuis cepat.
- **Target & Tantangan**: Pengaturan frekuensi mingguan dan galeri koleksi lencana pencapaian.
- **Leaderboard Global**: Tabel peringkat mahasiswa antar-universitas se-Indonesia.

## 🚀 Live Deployment
Aplikasi ini berupa berkas HTML/CSS/JS statis mandiri (*zero external dependencies*) yang dapat langsung dideploy ke **Cloudflare Pages** atau GitHub Pages.
